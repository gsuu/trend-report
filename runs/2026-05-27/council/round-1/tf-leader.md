# Round 1 — tf-leader (외부 벤치마크 시점)

> 직전 벤치마크(`tf-leader-report.md`) 5건 평가에서 *우리 우월 3 / 외부 보완 2 / 외부 대체 0*. 외부에 *우리를 대체할* 자료는 없었지만, 우리 글의 **구조적 약점 4가지**가 드러났다 — (1) dev 항목의 *프로덕션 적용 사례* 부재 (Smashing 합성 데모로만 끝남), (2) dev 항목의 *공식 사양 인용* 부재 (MDN·W3C 링크가 안 묶임), (3) service 한국 라이브 정책 항목에 *글로벌 비교 사례* 부재 (Sephora·Nordstrom 같은 동일 정책 유무 정보 없음), (4) design 카테고리의 *큐레이션 매체(Hover States·Awwwards) 단일 경로 의존* (브랜드 자사 사이트 직접 탐색 라운드 없음).
>
> Round 1에서는 이 4가지 약점 + 1가지 구조 개선을 *다음 회차부터 적용할 운영 결정*으로 변환해 제출.

---

## 안건 1. dev 항목 인용 표준 — "프로덕션 사례 1개 + 공식 사양 1개"를 *최소 인용 단위*로 강제

- **입장**: ✓ 동의
- **점수**: **+2**
- **근거**: 직전 벤치마크에서 *sibling-index()* ★ 항목에 대해 외부 후보 중 **thoughtbot의 자사 마퀴 리팩토링 케이스 스터디**가 *프로덕션 적용 신뢰 신호*로 우리보다 단단하다고 판정됨. 우리는 *iOS Safari 26.2 stable + 4패턴*에서 외부보다 풍부했지만 *production에 누가 썼나*가 비었음. 같은 맥락에서 Gap Decorations 항목도 *W3C css-gaps-1 사양 링크*가 묶이면 자급 완성. 외부 톱 매체(MDN·W3C·thoughtbot·CSS-Tricks)들은 *합성 데모 + 사양 + 프로덕션*을 *기본 인용 단위*로 운영하는데, 우리는 *Smashing 합성 데모 + 한국 컨텍스트 적용성*에서 그침. 한 줄 결손이 *카카오·토스 퍼블리셔의 PR 머지 결정 신뢰 신호*를 좌우.
- **실행 (다음 회차부터)**:
  - `docs/dev-digest-agent-prompt.md`에 *"매거진 dev 본문은 1) 합성 데모 또는 한국 컨텍스트 + 2) 공식 사양 링크 (MDN·W3C·Chrome Status·caniuse) + 3) 프로덕션 적용 사례 1개 (thoughtbot 류 케이스 스터디 또는 production GitHub 코드) — 3종 인용을 본문 내 별도 단락으로 묶는다"* 추가
  - `news-tracking/dev-sources.json`에 thoughtbot 블로그 RSS · MDN 신기능 페이지 · web.dev case study · CSS-Tricks Almanac 추가 (Smashing·Codrops·Chrome blog 3매체 의존 깨기)
  - `magazine-reviewer` 9개 점검 항목에 *"dev 카테고리에 한해 인용 3종 최소 단위 충족 여부"* 항목 추가
- **CTTD 컨텍스트 정렬도**: 퍼블리셔 30명이 직접 production PR을 머지하는 직무라 *프로덕션 사례 인용*이 회사 전체에서 가장 빨리 비용 절감.

## 안건 2. service 한국 라이브 정책 항목에 *글로벌 비교 사례 1건* 항상 동봉

- **입장**: ✓ 동의
- **점수**: **+2**
- **근거**: 직전 벤치마크에서 *무신사·29CM 강등 유예 3개월 자동 적용*은 한국 라이브 정책 중 유일 사례로 확인됐다. 하지만 외부 검색 과정에서 *글로벌 멤버십 정책 비교 사례*(Sephora Beauty Insider·Nordstrom Nordy Club·Macy's Star Rewards)가 우리 references에 완전히 비어 있다는 것이 드러남. 한국 PM이 *"올리브영도 강등 유예 자동 적용해야 하나"* 결정할 때 *글로벌 동일 정책 유무*가 의사결정의 절반인데 우리 매거진은 한국 사례만 단독으로 던지고 끝남. 글로벌 매체(BoF·Retail Dive·Glossy·NRF·Forrester) 한 건만 같이 묶어도 *기획자 10명의 클라이언트 회의 결정 도구*로 강해짐.
- **실행 (다음 회차부터)**:
  - `docs/service-digest-agent-prompt.md`에 *"한국 라이브 정책 사례를 ★ 또는 본문 1순위로 다룰 때, 글로벌 동일 카테고리 정책 1건을 *비교 단락*으로 항상 동봉 (없으면 '글로벌 동일 정책 없음' 명시)"* 추가
  - `news-tracking/service-sources.json`에 BoF·Retail Dive·Glossy·NRF·Forrester 추가 (글로벌 뷰티·패션 멤버십·결제·온보딩 정책 트래킹)
  - `target-classifier`에 *"service 한국 정책 항목은 글로벌 비교 1건 동봉 여부도 priority 가산점"* 룰 추가
- **CTTD 컨텍스트 정렬도**: 기획자 10명의 클라이언트(올리브영·아모레·CJ ONE·SSG·11번가) PM 회의 결정 도구가 한국 단독에서 *한국+글로벌 1:1*로 단단해짐. trend-radar의 K-뷰티 인디 수출 21% 같은 *글로벌 동선*과도 정확히 연결.

## 안건 3. design references에 *분기 1회 브랜드 자사 사이트 직접 탐색 라운드* 추가 (큐레이션 매체 단일 경로 의존 깨기)

- **입장**: ✓ 동의
- **점수**: **+1**
- **근거**: 직전 벤치마크에서 *Bécane Paris*(여성 모터사이클 D2C) 항목 비교 시, 외부에서 STELLAR Moto Brand·REV'IT! Heritage 두 *브랜드 자사 캠페인 페이지*가 보조 인용 가치를 가졌다. 이 두 사이트는 Hover States·Awwwards·Siteinspire·Lapa Ninja 큐레이션에 *안 잡힘* — 자사 D2C 캠페인 페이지를 직접 카테고리별로 탐색해야 발견 가능. 현재 design-reference-scout v2는 *큐레이션 매체 11경로* 중심이라 *브랜드 자사 사이트 카테고리 직접 탐색*이 0건. 시니어 디자이너 회의록에서도 *"한국 패션 클라이언트 응용처가 명확한 자사 캠페인 페이지"* 케이스 풀이 약하다는 wish 1순위가 같은 결손.
- **실행 (다음 회차부터)**:
  - `design-reference-scout`에 *"분기 1회 (예: 첫 주 회차) 큐레이션 매체 탐색을 50%로 줄이고, 카테고리별 브랜드 자사 사이트 직접 탐색(여성 D2C·럭셔리 뷰티·모터·아웃도어·캠핑 등) 50% 라운드를 별도 phase로 운영"* 룰 추가
  - 카테고리별 자사 사이트 시드 리스트를 `news-tracking/design-brand-sites.json` (신규)에 누적 — 이번 발견(STELLAR·REV'IT!) 즉시 시드 등록
  - 큐레이션 매체와 *동일 비중으로* 1회 라운드 운영 (단, *매주는 아님* — 분기 1회 안건이라 운영 부담 cap)
- **CTTD 컨텍스트 정렬도**: 디자이너 180명의 클라이언트 시안 *시각 케이스 풀*이 큐레이션 매체에 한정되는 구조적 약점을 깨는 안건. 시니어 디자이너 wish 1순위(국내 패션 브랜드 디자인 시스템 운영기·K뷰티 캠페인 케이스)와도 같은 결.

## 안건 4. *한 매체 의존도 ≤ 35%* 룰 — 카테고리별 발견처 다양성 정량 게이트

- **입장**: ✓ 동의
- **점수**: **+1**
- **근거**: 외부 벤치마크 과정에서 dev 카테고리는 *Smashing·Codrops·Chrome blog 3매체*에 사실상 의존(7건 중 5건), design은 *Hover States 60%*까지 비중 끌어올렸지만 여전히 단일 매체 의존 위험, service는 *한국 뉴스룸 + 토스피드*에 80%+. 외부 톱 매체(BoF·Smashing·CSS-Tricks)는 *자체 매체 자산*이라 단일 매체 의존이 자연스럽지만, 우리는 *큐레이터*라 매체 다양성이 *우리의 차별 자산*. 한 매체 의존이 깨지면 *그 매체가 한 주 쉬어도* 매거진 품질이 안 흔들리고, *서로 다른 매체의 같은 주제 글*을 비교 인용할 때 글 자체가 단단해짐.
- **실행 (다음 회차부터)**:
  - `digest-collect` Phase 4(타겟 적합성 분류) 출력에 *"카테고리별 발견처 분포 — 한 매체 점유율 ≤ 35% 충족 여부"* 게이트 추가
  - shortlist 작성 시 한 매체가 35% 초과면 *다음 매체에서 같은 priority 후보 우선 승격*. 이미 35% 넘은 매체 후보는 priority 동일 시 후순위
  - `runs/_feedback/preferences.json`에 *발행처별 누적 점유율*도 같이 기록 (현재는 도메인 단위만)
- **CTTD 컨텍스트 정렬도**: trend-radar가 *outstanding·mobiinside·careet·longblack·platum* 5경로 분산을 이미 정착시킨 모델. 같은 패턴을 매거진 본 라인에 옮기는 안건.

## 안건 5. *외부 벤치마크 정기 운영* — 분기 1회 → 격주 1회로 빈도 상향 + ★ 항목 *전수 비교* 의무화

- **입장**: ⚠️ 조건부 (운영 부담 큼 — 토큰·시간)
- **점수**: **+1**
- **근거**: 이번 첫 회차 벤치마크가 *5건 평가에 WebSearch 7회 + WebFetch 8개*로 끝났고, 그 한 번에서 *4가지 구조적 결손* 발견. 격주 1회로만 돌려도 *우리 ★ 항목 누적 4-6건 / 회*를 외부와 비교할 수 있고, *외부 대체 후보 발견 시 다음 회차 magazine-writer가 글을 다시 쓰는 피드백 루프*가 생긴다. 단, *매주 운영*은 토큰·시간 부담 큼 (senior-meeting 자체가 시니어 3명 + tf 1명 + trend 1명 = 5에이전트 병렬). *격주 1회 + ★ 항목 전수 비교*가 현실적 균형. 조건부 — *격주마저 부담스러우면 월 1회로 후퇴 가능*.
- **실행 (다음 회차부터)**:
  - `senior-meeting` 스킬에 *"격주 토요일(매 짝수 주) tf-leader 자동 호출"* 옵션 룰 추가
  - tf-leader 입력 우선순위에 *"직전 2주간 senior가 ★ 매긴 항목 전수"* 명시 (현재는 사용자 명시 또는 시니어 ★ 선택)
  - 격주 운영의 *토큰 부담* 측정 후, 1개월차에 *월 1회 후퇴 또는 격주 유지* 사용자 판단
- **CTTD 컨텍스트 정렬도**: 외부 벤치마크는 *우리 매체 자존심을 깨는 유일한 메커니즘*. 정기 운영이 없으면 시니어가 *우리 안에서* 평가하는 데 머물고, *우리 vs 외부* 격차는 영원히 측정 안 됨.

## 카테고리별 우선순위 정리 (tf-leader 시점)

- **dev** — 안건 1(인용 3종 강제)이 가장 빠른 효과. 다음 회차부터 thoughtbot·MDN·W3C 보조 인용 즉시 적용 가능.
- **service** — 안건 2(글로벌 비교 동봉)가 *기획자 10명 직무 직결*. BoF·Retail Dive·Glossy 시드 추가 즉시 가능.
- **design** — 안건 3(브랜드 자사 사이트 직접 탐색)이 *큐레이션 매체 단일 경로 의존 깨기*. 분기 1회 운영 부담 적정.
- **공통** — 안건 4(한 매체 의존 ≤ 35%)와 안건 5(외부 벤치마크 격주 운영)는 모든 카테고리에 동시 적용되는 *시스템 룰*.
