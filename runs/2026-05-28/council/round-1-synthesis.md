> 안건: "각 상세 페이지에서 정말 중요한 내용만 남기고 본문 분량·구성을 어떻게 줄일 것인가." 호당 글 수(25건)·채널·발송은 안건 밖.

## 합의된 안건 (7개 — 사실상 전원 같은 그림)

- **A. 인사이트 소제목 4개(DEV 3개) → 2개 통합** — 5/5 ✓ 평균 +2.0. *바로 끝판왕 계획 포함.*
  - DESIGN: `왜 참고할 만한가`+`디자인 관점` → 1개, `어디에 적용`+`점검질문` → 1개 (designer 제안)
  - SERVICE: `왜 지금`+`사용자는 무엇을 덜 해도 될까` → 1개, `설계 관점` 유지 (planner 제안)
  - DEV: `왜 지금`은 리드 한 문장으로 흡수, `구현 관점`+`실무 적용` → 2개 (publisher 제안)
- **B. 점검 질문 3개 → 1개 (한 문장, ~60자)** — 5/5 ✓ 평균 +2.0. *포함.* (DEV는 원래 점검질문 없음)
- **C. 요약 불릿 6개 → 3~4개, 불릿당 1~2문장** — 5/5 동방향 평균 +1.25. *포함(조건부).*
  - 조건: planner=정책·수치 사실 불릿 사수 / publisher=DEV 첫 2불릿에 기술명·조건 강제 유지 / designer=자체 완결성 위해 4개까지 허용.
- **D. 글 1편 목표 ~2,800~3,200자 구조 상한** — 5/5 ✓ 평균 +2.0. *포함.* (현재 ~7,200자의 약 40%)
- **E. 통일 골격 + 카테고리 1요소만 차등** — 5/5 동방향 평균 +1.0. *포함(조건부).*
  - 골격 통일(요약+인사이트 2소제목), 마지막 블록만 차등: DEV=관련자료 링크줄 / SERVICE=정책·응용+점검질문 / DESIGN=장면+점검질문.
- **F. 직전 council 의무 요소 = 삭제 아닌 "압축" (단락 → 한 줄)** — 5/5 동방향. *포함.*
  - 한국 응용 단락 → 한 줄(점검질문과 통합) / trend-radar 인용 → 한 줄 / DEV 한국 4축 → `구현 관점` 안 한 문장.
- **G. 인용(DEV 3종/SERVICE·DESIGN 2종) = 본문 산문 → `관련 자료` 링크 줄로 이동** — 4+ ✓ 동방향. *포함.*
  - 인용 정보 100% 유지, 본문 분량은 0에 가깝게. 라벨 줄(`[합성 데모]·[공식 사양]·[프로덕션 사례]`).

## 충돌된 안건 (0개)

이번 라운드 정면 충돌 없음. 직전 council이 "본문에 더하라"였고 이번이 "본문을 줄여라"라 정면 충돌이 예상됐으나, 5명 모두 **"삭제가 아니라 압축(단락→한 줄, 산문→링크 줄)"**으로 같은 답에 수렴. 의무 요소의 *정보*는 다 살리고 *형식(산문 분량)*만 줄이는 데 5명이 일치.

## 미언급/세부 미정 안건 (다음 라운드 확정 필요, 충돌 아님)

방향은 합의됐으나 *정확한 숫자·구현 디테일*이 페르소나마다 미세하게 다름 — 다음 라운드에서 단일 수치로 확정 요청:

- **목표 분량 정확값**: designer/planner ~3,000자, publisher ~2,800~3,200자, tf-leader ~2,500~3,000자, trend-hunter ~3,000자. → **단일 상한값 합의 필요** (예: "본문 3,000자 이하 권장 / 3,500자 절대 상한").
- **요약 불릿 정확 개수**: 3개 vs 3~4개 vs (수치 보존 시 4개). → **"3~5개, 불릿당 2문장 상한, 채움 불릿 금지"로 확정 가능한지.**
- **인사이트 소제목 통합 후 정확한 명칭**: 잠금 소제목 셋을 새로 정의해야 함(현재 docs/magazine-writing-standard.md의 4개 고정 표를 2개로 교체). → **카테고리별 새 소제목 2개 명칭 확정 필요.**
- **점검 질문과 응용 한 줄의 통합 형태**: planner는 "점검 질문 = 클라이언트 응용 질문"으로 일석이조 제안. → **이 통합을 공식 포맷으로 박을지 확정.**
- **DEV 점검 질문 부재 처리**: DEV는 점검 질문이 없어 마지막 블록이 `같이 보면 좋은 기술(옵션)`+인용 링크줄. → **DEV 마지막 블록 표준 확정.**
