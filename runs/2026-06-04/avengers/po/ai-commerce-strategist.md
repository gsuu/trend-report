## ai-commerce-strategist

대상: shortlist 2026-06-04 SERVICE 섹션(CJ온스타일·우아한공방·무신사·올리브영·Sephora/Ulta·오늘의집).
관점: 외부 AI 유입 → 전환 화면 → GEO 상품데이터 → PLP/검색/홈 추천 부착 지점.

---

### ① 전략에 반영 — 화면/데이터 작업으로 떨어지는 것

**CJ온스타일 (#1, P0) — 외부 AI 유입 플로우의 유일한 수치 근거**
- 화면 단위로 가장 명확. ChatGPT 앱 → 상품 탐색 → 방송 확인 → 공식 앱 연결, 이 3단 핸드오프 화면이 실재한다. 데모가 아니라 "5/1~25 대화형 유입 1월 比 4배, 자체 앱 AI 추천 유입 37%↑" 두 개의 분리된 수치(외부 유입 / 내부 추천)가 같이 나온다.
- 우리 작업: (a) **GEO 데이터 레이어** — 검색 표현·리뷰를 상품 데이터에 흡수하는 재구성 스펙. "AI 최적화 상품 60만→100만"은 곧 상품 데이터 정규화 백로그라는 뜻. 우리 카탈로그에 적용할 필드(검색 표현 동의어, 리뷰 요약 속성, 사용 맥락 태그) 정의가 첫 작업.
- (b) **외부 AI → 상품상세 랜딩 화면** — 외부에서 들어온 세션은 컨텍스트(왜 추천됐는지)를 잃고 도착한다. 랜딩 상단에 "AI가 이걸 추천한 이유" 블록 + 다음 액션(방송/장바구니) 고정이 전환 핵심. CJ는 이걸 "방송 확인" 단계로 풀었다.

**무신사 트렌드 큐레이션 (#3, P1) — 추천을 화면에 붙이는 방식의 모범**
- 핵심 설계 결정 하나가 우리에게 직접 쓸모. **"프론트는 단순 필터 버튼 UI, 백엔드는 트렌드→상품 매핑 파이프라인."** AI를 별도 UI로 노출하지 않고 기존 필터 자리에 얹는다 — 학습비용·이질감 0, 기존 PLP 골격 유지.
- 우리 작업: PLP/검색 결과 상단에 "트렌드 칩" 형태로 외부 신호 매핑 결과를 노출. AI 티 안 내고 전환만 가져가는 패턴. 단, "모자 카테고리 우선" = 좁은 카테고리부터 검증하는 단계적 롤아웃이라는 점도 그대로 가져갈 것.

**Sephora vs Ulta (#5, P1) — 추천 화면 노출 개수 A/B의 살아있는 대조군**
- 가장 실전적인 화면 파라미터. Sephora 3~4개 간결/대화식 vs Ulta 11~12개 카테고리별+후속질문. 같은 뷰티 도메인에서 정반대 노출 정책 → 우리 추천 화면의 "개수 × 후속질문 유무"를 정할 때 그대로 비교 프레임이 된다.
- 우리 작업: 뷰티 추천 모듈 설계 시 노출 개수를 고정값이 아니라 **의사결정 변수**로 두고, "탐색형(많이)·확신형(적게)" 진입 맥락별로 분기. 얼굴 사진 업로드 기반(Sephora)은 진단형 추천 입력 화면 레퍼런스.

### ② 거품 경고 — 전환 근거 없이 단어만 화려한 것

- **무신사 "선제적 큐레이션" 워딩** — "사용자가 찾기 전에 AI가 답한다"는 PR 카피. 보도자료(2026-06-03)뿐이고 이탈률 감소·CTR 상승은 **목표치이지 결과 수치가 아니다.** 화면도 "모자 카테고리"만 깔린 초기 단계. 전략 반영은 설계 패턴(필터 UI + 백엔드 매핑)까지만, 효과는 미검증으로 표기할 것.
- **Sephora/Ulta** — Glossy 팟캐스트 기반, 발표(3월/4월)는 있으나 전환·매출 지표 없음. "Amazon 대응 베팅"이라는 서사 중심. 노출 개수 설계 대조로는 1급 자료지만, "에이전틱 쇼핑이 다음 빅씽" 주장 자체는 검증된 결과가 아니라 베팅이다.
- **우아한공방 RAG 챗봇 (#2)** — 잘 만든 엔지니어링 글이지만 **커머스 전환과 무관**. 디자인시스템 내부 운영도구다. AI 커머스 전략 관점에선 유입·전환 0. design_dev_reference로만 가치 있음. 커머스 효과로 끌어다 쓰면 거품.

### ③ 측장(senior-planner)에게 넘길 쟁점

1. **외부 AI 채널 진입 우선순위 결정** — CJ는 ChatGPT Apps 전용 앱을 직접 만들었다(개발 투자). 우리는 (a) ChatGPT Apps 전용 앱 / (b) GEO 데이터만 정비해 AI 검색에 잘 읽히게 / (c) 둘 다 중 어디부터? 4배 유입은 매력적이나 전용 앱은 개발·운영 리소스 큰 결정. → 측장 판단 필요.
2. **GEO 데이터 재구성의 소유권** — 검색 표현·리뷰를 상품 데이터에 흡수하려면 카탈로그/MD/개발 협업이 필요. "상품 100만 개 최적화"급 작업은 누가 오너이고 어느 분기에 넣는가.
3. **리뷰 별점 공개 통제권 (DESIGN #7 네이버, 커머스 인접)** — 사업주 ON/OFF 옵션 정책. 우리 입점 셀러 운영도구에서 별점·리뷰 노출 통제권을 누구에게 얼마나 줄지는 정책 결정 사안 → 측장 영역.
4. **추천 노출 개수·후속질문 정책의 표준화** — Sephora/Ulta 대조를 우리 가이드라인으로 못박을지, 카테고리별 자율로 둘지.
